1. Install the extension

  1. Install the browser extension from the Chrome Web Store.
  2. Open your browser game or supported page.
  3. Use Activate in Tab to enable browser keyboard or gamepad emulation directly in the current tab.

2. Connect your controller

  1. Pair the DualSense with Windows over Bluetooth.
  2. Open the extension and connect the controller.
  3. Allow audio/tab capture when the browser asks for permission.
  4. Make sure audio sharing is enabled so sound can play through the controller.
